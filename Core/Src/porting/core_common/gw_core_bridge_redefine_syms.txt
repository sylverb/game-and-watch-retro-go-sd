# core_common symbol renaming (objcopy --redefine-syms), shared by every
# standalone core built from cores/_template/. Applied to every object file
# that makes up a core EXCEPT gw_core_bridge.o itself (which defines the
# core_<name> targets below) — see cores/_template/Makefile.
#
# Format: OLD_NAME NEW_NAME (one per line). NOTE: objcopy's parser does not
# tolerate blank lines in this file (fails with "missing new symbol name"),
# only '#' comment lines and NAME NEW_NAME lines — keep it that way.
#
# Add a line here + a trampoline in gw_core_bridge.c whenever a core's link
# fails with "undefined reference to <libc/firmware function>". See
# Core/Src/porting/core_common/gw_core_bridge.c header comment for what is
# intentionally NOT covered yet (setjmp/longjmp, __aeabi_ldivmod/uldivmod).
# --- libc: string.h ---
# NOTE: memcpy/memmove/memset are intentionally NOT here — gw_core_bridge.c
# defines real, local implementations of those (and the whole __aeabi_mem*
# family below) instead of routing them through the ABI, because they are
# by far the hottest calls a classic core makes (scanline blits, CD sector
# reads, audio buffer fills, ...) and the extra ABI indirection was
# measurably causing frameskip/audio glitches (see gw_core_bridge.c). Only
# rename memcpy/memmove/memset here if you deliberately want to go back to
# routing them through the firmware instead.
